HYPELINE · LANDING PAGE

Ten directions

Each board explores a different idea of what the page is. Same product, same copy facts, different visual thesis. Pastel throughout. Pick one and it becomes the system for the whole app.

01HeatmapThe hype curve is the hero object; the input sits on the timeline. Warm cream, serif, one lilac accent.
02RisoTwo-ink risograph print: misregistered headline, chat ticker ribbon, stamp. Loud, poster-like.
03ChatLogThe right half is a live chat replay spiking; Hypeline answers as a system message. Product demo as layout.
04DeskCorkboard of pinned moment cards with tape, string and handwriting. Tactile, friendly.
05SwissStrict 12-column grid, giant mono timestamp, hairlines, lavender field. Editorial and precise.
06WindowsRetro-OS windows on a dotted baby-blue desktop; each window is a real app state. Playful, nerdy.
07VerticalThe 9:16 cam + game clip is the centrepiece, with the app's yellow caption style; steps as a rail.
08BlueprintEngineering drawing of the no-server pipeline: white lines on periwinkle grid, title block, dimension line.
09FilmStripIrregular masonry of film frames, one per moment, each in its own pastel wash. Content-first.
10SentenceOne enormous sentence with marker-highlighted words and an underline blank as the input. Radical minimal.
Facts used on every board come from the working app: 5,626 messages / ~4 s on a 6h24 VOD, the 0:34:15 peak (6.2× baseline, 41 chatters), 16:9 · 9:16 · cam + game, captions, thumbnails, NanoGPT BYOK, MIT.
